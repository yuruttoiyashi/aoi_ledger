# 青色帳簿 Phase 1

自分専用の青色申告・収支管理アプリのPhase 1です。PC中心で、日々の売上と経費を簡単に記録し、内部では複式簿記の仕訳を自動生成します。

## 今できること

- 1日単位の売上合計・チップ記録
- 経費を1件ずつ登録
- レシート画像をブラウザ内に保存
- 家事按分（事業利用割合）の自動計算
- 私用カードで払った事業経費を「事業主借」で自動仕訳
- カード明細CSVの取込と、事業・私用・按分の振り分け
- 売上・経費から仕訳帳を自動生成
- 月次の売上・経費・利益・税社保積立目安を表示
- 売上・経費・仕訳帳のCSV出力
- データとレシート画像を含むJSONバックアップ／復元

> 現在はブラウザのローカル保存を使うMVPです。Cloudflare D1/R2、Cloudflare Access、レシートAI読取は次のPhaseで追加する想定です。

## Windowsで起動する

### いちばん簡単

`start.bat` をダブルクリックしてください。

### VS Codeのターミナルから

このフォルダで次を実行します。

```powershell
npm run dev
```

表示されたあと、ブラウザで次を開きます。

```text
http://localhost:4173
```

終了するときはターミナルで `Ctrl + C` を押します。

**Pythonは不要です。Node.js / npmだけで起動します。**

## ビルド

```powershell
npm run build
```

`dist` フォルダに公開用ファイルが作られます。

ビルド後の内容を確認する場合は、

```powershell
npm run preview
```

を実行し、`http://localhost:4173` を開いてください。

## テスト・構文チェック

```powershell
npm test
npm run check
```

## 大切な注意

このPhase 1は帳簿入力を助けるためのアプリです。税額・国民健康保険料・青色申告控除の適用可否を自動確定するものではありません。確定申告時には最新の税制と実際の取引内容を確認してください。
